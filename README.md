# MovieAdmin

MovieAdmin is a small web application designed to manage movie information,
ratings, and reviews. It serves as the administrative backend for a larger 
information system, inspired by the platform Rotten Tomatoes!
This module provides the foundation for storing movie details, 
organizing rating information, and preparing structured content.

As development continues, MovieAdmin will intergrate with
additional components such as a public movie browser, 
review submission features, and external data sources.

At this early stage, the project contains basic
scaffolding and initial setup, and will expand as 
the rest of the system is built.
